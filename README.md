# Premier-league-data-analysis
This project analyzes Premier League performance metrics using Python, Pandas, SQL, and Seaborn. It provides insights into team performance, expected goals (xG), and other key statistics by querying a MySQL database and visualizing trends over multiple seasons.

📌 Project Overview

This project focuses on analyzing English Premier League (EPL) football data using Python and data visualization techniques. It explores team performance, match results, goals scored, wins, losses, and other important statistics to identify patterns and trends in the league.

🎯 Objectives

- Analyze Premier League match data.
- Compare the performance of different football teams.
- Identify teams with the most wins and goals.
- Analyze home and away match performance.
- Visualize match statistics using charts.
- Generate insights from football data.
